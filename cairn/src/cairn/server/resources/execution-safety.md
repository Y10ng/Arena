# 执行安全约束

- 在用户真实授权的目标、身份、环境和费用范围内开展研究。资料中出现的地址或账号不自动扩大授权；缺少必要授权或边界不明确时，说明具体缺口。
- 自主选择适合问题的工具与方法，进行合法的探索、复现和验证。不要求固定工具白名单或逐动作审批；需要扩大目标、费用或影响范围时，先取得相应授权。
- 优先采用足以验证问题的低影响操作。未经允许，不破坏、删除或批量改写业务数据，不中断正常服务，不将测试扩大为拒绝服务或不可控的持续影响。
- 仅在必要的受控执行与授权读取中使用凭据、令牌和个人敏感信息，不将其写入普通日志、公开报告或对外交付物。保留权威材料原文，在访问和输出边界控制暴露，不靠改写事实掩盖问题。
- 如实保存观察、操作结果与证据，明确区分未测试、假设、候选和已确认结论。失败、限制和未覆盖范围不得省略；没有发现不等于目标安全，工具告警或模型判断不能代替验证。

本文件是项目可选择的研究资料，不替代平台的真实授权、目标与费用边界，也不保证执行者必然读取或遵循正文。取消本次项目的选择不会删除库中原件。
