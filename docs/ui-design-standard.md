# 全站 UI 设计规范

> **2026-10-31 最新澄清：「现在的整体包括字体，就像浏览器再缩放10%的效果」。** 以当前已发布界面为逻辑基线，整体等比例显示为90%，包括文字、图标、控件、间距、侧栏和Portal；不是继续分别改字号或留白。此次明确澄清覆盖此前不采用整页zoom的取舍，不改变用户浏览器设置、不新增密度开关。继续由监督／原astra实施会话完成同轮返修，不使用gpt-6.1-sol。第3节是唯一现行设计要求；技术交付不冒称用户已认可。实际进度见[全系统 UI 重设计方案](specs/global-ui-redesign.md)第24节，流程见[前端 UI 实施 SOP](frontend-ui-sop.md)，产品与工程边界遵循 [AGENT.md](../AGENT.md)。

## 1. 设计目标

Arena 是内部自主安全研究工具，而不是营销网站或统计看板。设计围绕：表达目标、持续研究、找到有价值的发现、阅读证据、复测、交付与复用。

- 简洁、有高级感。质感来自排版、留白、比例、层级、细节和稳定操作，不靠大面积渐变、装饰卡片墙或特效。
- 全系统统一：登录、导航、项目、Agent、成果、证据、复测、报告、资料、模型、Worker、配置、监控，以及所有浮层和异常状态。
- 主菜单按用户最新要求保留原布局与真实分组；其余不合适的 Shell／页面结构不作兼容目标。保护能力、数据、权限、状态与深链接，不扩展为 Agent 专属视觉。
- 统一语言，不统一页面形状。比较对象用列表，读证据用阅读器，编辑配置用表单，对话用连续正文；不把所有业务做成聊天或卡片。
- 界面使用简体中文，专业术语和协议名可保留英文；图标统一 Lucide，不用 emoji，不增加语言切换。

具体观察与取舍：

- Tasks 实测普通行约 49px、正文 14px、筛选按钮 32px；Sidebar 07 收起后约 48px。它们只说明参考组件的密度关系，不覆盖第3节依据最新反馈修订的尺度。Dialog 访问后实际为 Base UI 示例，不冒称验证了 Radix 实现；其约 384px 宽、16px 内距适用于短表单，不照搬到 Arena 长复测输入。
- tweakcn 的主题切换同时影响表面、文字、日历、图表、按钮与菜单；调整圆角后查看实际渲染，而不是仅记录输入值。Arena 延续第 3 节唯一基线，重点贯通 hover／focus／disabled、Portal 与浅深主题，不把换成某个预设当作重设计完成。
- Blur Fade 源码包含 `opacity`、位移、`filter`、顺序延迟和一次性 in-view 判断。本次在 `prefers-reduced-motion: reduce` 下重播，仍看到透明／模糊／位移起始态；这只说明该演示没有自动跳过该起始效果，不代表全库无无障碍支持。Arena 不让正文等待动画；减少动态偏好下取消入场位移、模糊和延迟。
- 未覆盖全部组件、主题与键盘组合。Tasks 的 Add Task 本次点击未观察到 Dialog，不算验证创建流程；tweakcn 字体选择器出现 Loading fonts，未完成字体切换；未保存、分享、生成或导出主题。公共示例研究不是 Arena 正式设计验收。

shadcn/ui 与 Magic UI 的 README 声明 MIT，tweakcn LICENSE 为 Apache-2.0；本轮借鉴设计方法，不复制组件源码，使用已有 Vue、Reka UI、Lucide。三个参考不拼成三套皮肤。旧 Cyber、Plane、Supabase、assistant-ui 等不再作为当前视觉依据；有效业务交互合同保留。

**落实要求**：参考研究先在分析阶段完成，再形成具体区域和交互取舍，不把“实施者再去学习”代替设计。第2节各次观察保留真实边界，当前实施以第3节及方案第23节为准，旧样板与已执行提示词不重复套用。用户提出新的视觉问题时定向补看完整布局和交互，不靠项目名称、README或token数值宣称达标，不机械移植React组件。

## 3. 唯一视觉语言：适度尺度 · 分组留白

用户明确否定U3正式页面的偏大、拥挤与单调，当前以最新反馈修订，不冻结此前样板尺寸。主菜单真实结构保留；正文优先不等于取消层次，同组操作靠近、不同用途留出间隔。浅冷灰画布、白色工作面、蓝紫主动作与局部辅助色贯穿浅深主题。尺寸与结构要求唯一见第3.5节；样板已经退出，不恢复独立演示工程。

当前修订同时覆盖布局、区域比例、信息层级、操作组织和视觉细节，不只是色板。不复制虚构记录、评审条、演示标记、占位菜单或本地假提交。历史样板展示范围不限制正式能力；多选、跨页查询、上传、草稿、请求保护、列宽调整、深链接和权限保留真实业务合同。

按各页任务重组不合适的页面和组件，不只叠一层 CSS；适合的逻辑与成熟交互复用。正式系统只保留一套主题及呈现，不新增平行应用、接口或新旧模式开关。样板未展示的配置、资料、计划、运行等按相同问题举一反三，不因没有截图而保留冲突旧骨架，也不强制所有工作面表格化。

### 3.1 表面与颜色

蓝紫主色、白色工作面与浅冷灰画布，侧栏保持淡底与明确选中；深色为同一语义的深蓝灰版本。由正式共享tokens承载，保留有意义的token名称并贯通消费者，不复制第二套主题。已有主题偏好保留，新用户默认浅色。

严重性、执行状态与验证结论各自表达，语义配色见第 3.5 节；高危仍使用小面积暖红。普通文字目标对比度至少 4.5:1，必要图标／焦点至少 3:1，不能仅由色表宣称全部合格。颜色不能替代文字；细线、留白和局部浅底区分主要区域，浮层与主按钮可用分级阴影和局部高光，不将工作区做成玻璃／发光背景或彩色卡片墙。

### 3.2 排版、留白与控件

所有尺寸以第3.5节当前修订基线为起点，结合真实页面调整，删除冲突的旧标题、行高与局部字体覆盖；不新增永久密度设置。字体使用本地系统无衬线与中文 fallback，代码用本地等宽字体，不引入网络字体。数字使用 tabular-nums，控件继承字族；名称弹性占宽，长内容在详情完整可达。

文字、图标、控件、间距与Portal使用同一逻辑尺寸体系；按用户最新明确要求，以单一全局90%显示比例共同缩小，不逐组件叠加缩放。视口与全屏区域仍须铺满窗口，浮层定位、滚动、编辑器及拖动坐标须保持正确；不改用户浏览器缩放偏好，不用transform仅改变绘制而遗留原占位。边界与圆角随整体比例缩小；空间不足仍正常换行，不用外层裁切隐藏内容。不机械复制样板固定列宽或虚构操作。

### 3.3 文字与信息层级

- 默认删除宣传词、设计宣言、重复副标题、同义状态和无用途标签；不把删掉的文字批量搬进 tooltip。
- 用户看见对象、状态、结果与动作，不必理解内部协议。正常配置不附一页设计说明。
- 保留必须的字段标签、真实错误、当前阻塞、未知受理结果、费用／授权边界和证据限制。
- 精简的是界面噪声，不是用户输入、研究结论或权威原件。不得为视觉清爽改写证据。

### 3.4 组件细节：不能只改默认态

以下是全站共用的细节标准，复用现有 UI／patterns 与成熟行为实现；缺项只补有真实调用方的能力，不为清单新建一套组件库。每个组件只验证自己实际拥有的状态，不制造无用途的变体。

| 组件族 | 必须贯通的视觉与行为 |
| --- | --- |
| Button／IconButton／链接 | 蓝靛主按钮、边框次按钮、文字动作；图标文字共轴，hover／pressed／focus-visible／disabled／loading 清楚；加载不改变宽度、不重复触发；危险动作独立；图标按钮有名称，链接保留真实语义 |
| Input／Textarea／密码／数字输入 | 细边界、统一控件字阶；label 独立于 placeholder，前后缀不压文字；错误关联字段并保留输入；readonly 可选取，disabled 不伪装可编辑；密码显示不误提交，数字单位不混入值 |
| Select／Combobox／原生 select | 同排控件等高，选中／悬停／焦点区分；长选项不挤箭头，菜单可滚动且不被裁切；键盘、Esc、搜索、清除、多选与原 option 值保留 |
| 筛选／排序／行菜单 | 搜索与常用筛选相邻，低频动作靠右并分组；已选值清楚，弹层选项共轴；遵循真实单选／多选合同，数量有真实范围；无匹配、重置、键盘与回焦可用；排序不以当前页反转冒充全量，菜单不吞业务能力 |
| Checkbox／Radio／Switch | 小面积强调、标签扩大点击区；勾选／indeterminate／disabled／focus 完整；全选遵循分页筛选语义；请求发出不等于保存成功 |
| FormField／表单分组 | 标签、输入与辅助字阶区分，说明靠近所属项；必填、格式错误、服务端错误和未知结果分开；File／长输入不丢失；高级区收起保值、不藏必填项，不加说明墙 |
| Table／行内详情／分页 | 轻表头、细横线、名称弹性列、操作列稳定；简单数据单行、复杂身份允许主次两层、详情完整可达；hover／selected 分开，保留列宽调整；一次展开一条、收起回焦；空态保留筛选，分页不虚构总数 |
| Tabs／分段视图／Breadcrumb | 视图细下划线，计数仅作辅助；路由 link 与局部 tab 语义区分；键盘可用，不丢编辑内容及返回上下文，不冒充后台全量统计 |
| Badge／状态／严重性 | 小圆点／图标、文字与语义浅底；严重性、验证结论、执行状态各自表达；未知／未复现／失败／成功不同，长错误展开阅读，不以闪烁呼吸灯冒充运行健康 |
| Tooltip／Popover／DropdownMenu | 单层轻边框、细阴影、菜单用操作字阶；hover／键盘可达，Esc／回焦正常，Portal继承主题与尺度；危险项独立，关键错误及禁用原因不只在 tooltip |
| Dialog／确认框／Drawer | 统一头身底栏，按实际内容确定宽度，不留装饰图标占位；正文独立滚动、动作可达；资料靠近正文，高级项折叠保值；标题描述关联、焦点锁定及关闭恢复；嵌套只关闭顶层，保留未保存保护；不用 Drawer 替代漏洞行内详情 |
| Alert／Toast／行内反馈 | 提示与正文有表面或边界区分，反馈使用语义色；保存／复制真实成功才报成功；失败就地恢复，未知结果不只用短暂 Toast；live region 不反复播报，错误可完整阅读 |
| Loading／Skeleton／Empty／Error | 与真实结构一致，不编数字或占位卡；首次加载、刷新、无数据、无匹配、无权限、失败区分；刷新不清旧内容，局部重试，不大幅跳动 |
| 文件／附件／上传下载 | 文件名、类型大小、状态与动作共线，长名可读；真实进度与等待区分，移除重试不丢其他附件，关闭不误清正文；下载真实文件，原件与预览区分 |
| Markdown／代码／Monaco | 正文、标题、列表引用和工具条遵循同一字阶；代码等宽，宽内容局部滚动；只读编辑明确，搜索错误滚动及浅深主题贯通；不执行外部 HTML，不重写原始内容 |
| HTTP／证据／日志 | 同一外框内成对请求响应、顶部对齐、各侧滚动；正文用协议字阶，诊断独立；Raw／Pretty、编码、缺侧、截断、复制、搜索、换行、放大及原件入口保留，复制不带行号，失败不报成功 |
| 图表／图谱／进度 | 同一文字语义色、细轴线低强调网格，不新增装饰统计卡；真实单位、图例、悬停选中及空错态保留；不强制表格化，涉及图形实施先按 dataviz 技能处理 |
| Shell／滚动条／容器 | 主菜单结构和真实分组保留，尺度按 3.5；保留折叠、搜索、权限入口，长导航自身滚动，低频入口可达；设置向上浮出，不加样板评审条；Portal、原生 option、日期文件控件继承主题，不叠第二套页面主题 |

横向检查同样重要：相邻控件同高、同基线，同类圆角不漂移；长中文、长 URL、空值、换行、选中文字、滚动条、浮层边缘、错误消息和焦点环不能被裁掉。共享组件改完后必须查看其真实消费者，页面内原生控件与业务局部 CSS 也在范围内，不能仅凭组件目录已改就宣布完成。

### 3.5 当前修订基线：适度尺度 · 分组留白

U3后已修订字号、分组与视觉；用户随后明确要求当前整体如浏览器再缩小10%。因此下列尺寸保留为90%显示前的逻辑基线，浏览器100%时应用整体90%，不再单独改小token叠加密度调整。字体、图标、间距、边框与浮层均同比例变化，视口可用范围另行正确换算，不能留下窗口底部空白。此前“不同比例挤掉留白”的要求用于信息组织设计，本次既有留白随整体等比缩小，不额外压缩分组。具体屏幕像素须区分逻辑值与显示值，不用数值符合代替真实页面和交互检查。

- **逻辑字阶保持，整体显示90%。** 缩放前正文／普通列表14.5px，主要控件与导航15px，辅助与标签12.5px，密集表格／流量13.5px，分区17px，对象标题19px，长阅读行高1.65。HTTP／Monaco配置仍使用逻辑14.5px，显示与其余界面一起缩为90%，不能为编辑器再次乘系数。保持操作与阅读不同层次，不把所有字号改成同一值。
- **主菜单保留结构与呼吸。** 侧栏248px、折叠68px、导航项42px并保留分组和间距，品牌区56px；现有图标在实际比例合适时保留，不为统一数字逐个重写。不把主菜单缩成密集数据行。保留原菜单位置、权限、真实分组和底部设置；Agent内部历史约190px，继续固定左栏，不回退下拉。
- **按功能关系分行，而不是按宽度塞满。** 视图／对象身份与主动作形成第一组；搜索／过滤／排序形成第二组。复杂列表页使用两层有意组织的紧凑工具区，层间12px；简单文件列表只有少量控件时可一层。不能把视图Tabs、五六个筛选和所有动作堆成一排，也不能每个按钮独占一行。常用过滤邻近搜索，创建／刷新等对象动作有稳定右侧位置，危险／低频动作沿已有菜单分组；不删除已有能力。
- **项目上下文与局部任务分开。** 允许对象身份／动作与项目局部导航分成两条各有职责的短带；也允许简短上下文同行，按真实拥挤程度决定。禁止重新引入重复大栏目名、层层面包屑和没有内容的高页头。标题可访问语义、返回与深链保留。
- **列表按内容类型取密度。** 简单数据表行约48px，流量行约34–36px；身份／说明确实有价值的模型、计划、运行对象可采用主次两层，基准约60px，有诊断等真实内容时可自然增高。不是所有行必须同高或单行：主行放对象与短状态，次行只放能帮助识别的次要信息，不能把Worker、ID、时间和全部诊断硬塞同一行；也不恢复重复的正常说明。完整诊断和长原文仍有原入口，关键异常／未知不能藏掉。
- **逻辑留白保持，随整体同比例显示。** 缩放前正文外距18px，区域间20–24px，同组控件8px，独立组16–24px；控件默认34px、紧凑30px、长表单38px，圆角控件8px、主要面板12px。留白、阅读面固定宽度与控件一起显示为90%，不额外重写局部spacing。配置页label／输入／保存按阅读顺序组织，编辑器工具不混入页面级导航；主要内容应早出现但不与上一组贴紧。
- **有色但有焦点。** 采用浅冷灰画布与白工作面，蓝紫主色、浅紫选中背景；主按钮可用近色渐变、细高光和轻有色阴影，导航选中与输入焦点呼应。可在既有模块图标底、区域小标记使用紫／蓝／青等局部辅助色，不新增统计卡或伪业务状态。工作面仍清楚、长正文仍中性；不把每块区域染成不同饱和色。深色使用深蓝灰表面与可读文字，不把浅色透明度照搬过去。
- **状态语义不被装饰覆盖。** 待确认／中危用琥珀、已核对用青、未复现用中性或蓝灰；执行完成可绿，但不等于漏洞确认／修复或安全。状态色与文字共同表达，品牌装饰不冒充状态，不新造健康度或运行灯。
- **按钮与浮层有连续反馈。** 主动作hover时高光／阴影轻增强，pressed恢复阴影并微下沉约1px；次按钮和图标按钮通过浅色底与边界反馈，不全部使用同样强烈特效。颜色／阴影约160–200ms，浮层入场约140–180ms；不做循环流光、持续呼吸、整页模糊或行尺寸动画，不用transition:all。reduced-motion取消位移与非必要动画，焦点仍清楚。
- **保留有效的阅读与操作结构。** 漏洞行内详情、复测分区／Tabs、成对HTTP原文、局部滚动、固定底栏和输入保护继续有效。只给主要区域边界，不给每字段套卡片；设置继续向上Portal且不推移按钮。所有简化只作用于展示，不能改写原文或删掉权限、状态、业务入口。

实施先以共享层、项目／成果列表、项目上下文验证比例与组织，再处理其他拥挤消费者；不恢复已退出样板、另建永久主题或密度切换。所有页面仍须核对实际影响，不以共享token传播或行高达标宣称全局设计已完成。

## 4. 全系统信息组织

- 单层全局导航负责业务域，当前对象内再用少量局部导航。配置／监控位于低频区；不把导航变成所有后端字段的目录。
- 导航、面包屑、页面名和命令入口从同一事实源维护；权限隐藏不替代服务端授权。
- 主要动作靠近对象。一个区域通常只有一个实色主要动作，其余为边框、文字或菜单；危险动作独立确认。
- 全局 Agent 是业务架构中的待实施能力，样板导航不证明已经支持；不因画出入口擅自迁移会话后端。
- 列表用足可用宽度；长正文控制行长，证据与表格不受同一窄阅读列限制。没有数据就留真实空白，不用假统计填满屏幕。

## 5. 页面模式与保留的业务要求

### 5.1 项目、计划、成果与管理列表

标题与动作 → 视图／筛选 → 单一列表 → 必要分页。不要默认添加统计卡片墙。搜索、筛选、排序必须有实际能力；样板的本地筛选须标明不接正式数据。

项目状态直接来自项目业务状态，不用 runtime 健康覆盖；运行诊断放实际需要的位置。不常驻逐行“上次状态”或调度解释。创建／控制请求未知仍在对应动作可见。

### 5.2 研究工作区与 Agent

当前研究、输入、已有成果和必要上下文有清楚主次。Agent 历史固定为左侧单行窄列表，不用下拉替代；项目导航并入必要上下文带，不额外占一条宽竖栏。成果／证据按需打开，不常驻空成果栏，不让聊天挤掉研究成果。

消息与输入共轴，正文连续阅读；工具回执表达动作对象、真实状态和结果入口，原始 JSON 按需查看。工具完成不等于漏洞确认。保留中文 IME 与现有发送快捷键，用户上翻不被新内容拉回；未发送输入与阅读位置有合理保护。

### 5.3 漏洞详情与证据

- 继续保留用户已明确的**记录下方行内详情**，同一列表一次展开一条，不再旁挂第二套漏洞抽屉。展开／切换／收起提供正确语义、焦点和未保存保护。
- 全局与项目内漏洞是同一事实的不同入口。深链接、来源复测返回和不在当前筛选内的定位记录保留明确行为，不静默修改筛选，不把定位条目计入命中数。
- 先看结论、成立条件、限制与证据；复现过程／修复建议按需切换，不能把候选写成确认。
- HTTP 用一个外框、共同交互标题、左右请求／响应，正文上下对齐、各自滚动；不要两张独立大卡片。内部细线、简短工具条、行号与正文留间距。
- Raw 保留当前读取原文，Pretty 只提供可靠格式化的派生视图，不回写原件；缺侧、截断、编码不确定和读取失败可见，不补造响应。
- 复制取对应侧原文，不带行号／格式化；实际写入成功后才显示成功，失败给可操作恢复路径。样板仅用虚构数据验证剪贴板，不读取用户已有剪贴板。
- 不增加重放、代理、拦截或访问目标能力。正式阅读器保留已有搜索、换行、放大与受控原件入口，样板不冒充完成全部功能。

### 5.4 复现／复测与报告

- 复测以结论／范围、对象字段、证据和过程构成有边界的操作界面，按可用空间分栏或纵排，不沿用三章文章式大段铺陈。请求／响应在证据内并排并可独立滚动；导出报告仍按正式文档用途呈现，不压成列表或塞进可编辑 textarea。
- “执行完成”“已确认”“未复现”“已修复”不同；未测不能说安全，未复现不能说已修复。
- 中途发现可以查看和导出，不把成果价值绑到项目结束；总报告的真实生成条件按业务合同，不由 UI 捏造。
- 原件、预览、历史结果与本次结果区分。无结果、失败、尚未生成不是同一个空态。

### 5.5 创建、资料与配置

- 简单上下文操作使用 Dialog；长期编辑／复杂资料使用独立工作面。不强制所有创建弹窗化。
- Origin／Goal 保留自由表达，不缩成固定 URL 表单；长输入纵排，附件入口靠近所属正文。必需字段直接可见，高级参数按需展开。
- 浮层标题、正文、底栏对齐；正文独立滚动，主要动作始终可到达。关闭子浮层不丢正文、File 或已选项。
- 资料与证据按任务选择主从阅读；一个对象不留空列表。预览不冒充完整原件，不执行外部 HTML。
- 配置一处编辑、明确生效范围；配置保存、连接验证和执行可用是不同事实。普通用户可管理自己的模型与复测配置，不能借改导航只剩管理员入口。
- 凭据不进入 URL、普通日志、截图或浏览器持久缓存；遵循现有受控展示与权限规则。

### 5.6 登录与异常

登录、空态、无权限、加载、失败与错误页同一主题。真实错误就地反馈、保留输入；不得用演示数据／静默成功掩盖失败。

## 6. 交互与动效

- hover／focus-visible／pressed／disabled／loading 有清楚反馈，焦点可见。禁用原因不能只藏在不可聚焦控件的 tooltip。
- 浮层使用成熟焦点管理，Esc 关闭顶层、关闭回触发器、背景不可交互；Portal 继承同一主题，嵌套浮层层级正确。
- 动效时长与范围统一按第 3.5 节；不模糊正文、不逐行迟到、不让文字跳动，不做循环装饰动画。
- 尊重 `prefers-reduced-motion`，动画不承担唯一信息表达。
- 表格、详情、编辑器、浮层有明确滚动归属；不靠最外层裁切掩盖内容溢出。合理保留筛选、选中、输入与滚动位置。

## 7. 实现归属与验收

- 历史02样板已退出，本轮直接修订正式工作区，不恢复 `density-preview/` 或旧 `design-preview/`。当前唯一视觉要求见第3节，不把历史样板认可当作对U4的认可。保留普通 `vite preview` 能力、正式服务、正式资源与历史hash。仅停止本轮可确认归属且不再需要的进程，不能批量结束用户浏览器、其他会话或Server／Dispatcher／数据库／Worker。
- 已选设计由唯一正式 `src/design-system/`、共享组件与页面模式承载；不长期维护样板、第二套主题或新旧路由开关。每批直接替换已迁移消费者的旧样式、布局与无效视觉断言，不先搭第三套包装层；删除其他旧代码仍须确认替代完成与无调用方，不能借收尾批量清理未知用户改动。
- 保持 Vue／TypeScript、已有 ReKa UI（包名 `reka-ui`）和 Lucide，不因参考项目切栈或擅自加依赖。
- 以最大化桌面整体效果验收；本轮采用 **1920×1080 CSS px、100% 等效桌面视口**，不冒称实体窗口已最大化。不默认安排移动端或多尺寸矩阵，不主动删除已有适配。
- 在相同桌面视口下检查正式路径完整画面，依照第3节当前修订要求与最新用户反馈，分别检查默认列表、展开详情和主要浮层的区域比例、阅读顺序、操作位置与细节，再操作主要路径；样板退出后不为对照重建演示入口。若正式结果仍是旧页面结构加新颜色／间距，应继续返工，不能靠“组件都改过”结案。真实业务导致的差异应说明对应能力和取舍；不追求虚构内容或固定列宽的机械复制。历史样板验证不代替正式系统按 SOP 验证；构建、DOM 与实施者自查不代替监督亲验及用户效果评价。
- 区分规范已写、样板方向已选、正式实现、系统加载、业务验证和用户认可。用户已授权按清晰列表推进全系统 UI，但仍沿既定分析／新实施分会话模式；实施会话按当前批范围修改正式代码，分析会话不得以总体授权自动越过分工或顺带启动非 UI 架构改造。
- “精细到每一个细节组件”意味着每个正式路由、项目内子页、浮层、共享／局部控件和实际状态都有明确归属；不仅看默认态和截图。样式被共享变更影响但布局／交互尚未核对的页面记作待迁移，不能算完成。浏览器原生文件选择器、系统日期选择器、beforeunload 警告属于浏览器外观边界，不承诺像素一致，不因此移除功能。
